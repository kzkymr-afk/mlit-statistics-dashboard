# 財務原値・利用範囲の公開投影

Atlas v0.3.2 の「財務の原値と利用範囲」は、BuildBase Source の審査済み財務利用 view から、従来と同じ1,400 Fact ID と元の `facts_effective.jsonl` を照合して作る閲覧用スナップショットです。元の全19,054 fact、raw25,332件、hold427件、保存過年度653セル、263系列の歴史的数値を公開データとして取り込まない。元の観測・許可・保留・Source台帳は変更しない。

今回の保存済み利用状態は、既存自動審査契約20、注記付き登録用途970、比較相手待ち356、算定基準保留42、独立対象context保留10、原表橋渡し保留1、総純資産への同一視禁止1、未審査0。観測1,400件は比較組数ではない。20＋970の990件でも、会社・原指標・実期間・単体/連結・単位・相手ID・出典版・必須注記に固定された既存契約以外は許さない。409件の比較未確認と禁止1件は異なる状態。相手待ち356件も原値は参照できるが、過年度の型付き値やstock時点、原定義との対応を個別に要する。

生成は `python3 scripts/build-financial-usage-public.py SOURCE_ROOT`。元の 2026-10-17 matrix の1,400 ID集合、2026-10-18 保存セル後の quality/usage overlay、P2利用制約台帳を版とSHAで固定して投影する。Sourceは読み取り専用。公開JSONは strict allowlist と公式HTTPS URLに限定し、ローカルパス・非公開URL・rawログ・保存セルID/数値を含めない。263件の当年系列に限って、品質/利用台帳の元 conditions・禁止用途・保存系列 conditions を欠落なく併合し、固定相手IDの存在を不透明な契約参照IDで示す。台帳SHAとそのFactのJSON pointerを保存する。24件のstock日付等の残件は残件文を表示する。

当年系列の条件はそのFYのFactのみに適用する。過年度の分母・配当区分・会計方針・地域範囲が同じという証明ではない。厳密前年比・精密差額・自動比較/合算・Source系列そのものの公開許可はfalseを維持する。この画面は新しい比較・合算の許可を作らない。年度ラベルから日付を生成せず、資料の取得日時がないときは未記録と表示する。保存済み公式資料と現在掲載版の一致も元記録の状態を保持する。長谷工91.7%の当年IDは今回の注記付き固定ペア状態に更新し、古い相手待ち説明文は削除した。

画面は検索・絞り込み・原値/出典/条件の確認専用。比較ワークスペースの系列、相関、グラフ、保存分析には追加しない。既存の四半期・企業スナップショット・公的統計のゲートは別のまま。公開asset schema v2の件数、品質/利用viewと台帳SHA、263件の当年制約フラグ、投影SHAをclientで検証する。
