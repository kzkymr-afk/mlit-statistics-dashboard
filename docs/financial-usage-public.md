# 財務原値・利用範囲の公開投影

Atlas v0.3.1 の「財務の原値と利用範囲」は、BuildBase Source の審査済み `20261017_financial_market_usage_guide/usage-matrix.json` の 1,400 ID を、その元の `facts_effective.jsonl` に ID と原本 SHA-256 で照合した閲覧用スナップショットです。Source の全19,054 fact、raw25,332件、hold427件や未公開の別候補を取り込んだ画面ではありません。元の観測・許可・保留・Source台帳はこの投影では変更しません。

観測1,400件は比較組数ではありません。公開区分は既存自動審査契約20、注記付き登録用途659、比較相手待ち667、算定基準保留42、独立対象context保留10、原表橋渡し保留1、総純資産への同一視禁止1、未審査0。20＋659の679件でも、利用は会社・原指標・実期間・単体/連結・単位・相手ID・出典版・必須注記に固定された既存契約に限ります。667件は原値参照ができ、登録済み式の入力となる9 IDは当該式の条件内で検算できますが、別の観測との一般比較許可ではありません。720件の比較未確認と禁止1件を混同しません。

生成は `python3 scripts/build-financial-usage-public.py SOURCE_ROOT` を明示的に実行します。Source は読み取り専用で、厳格な項目 allowlist、公式HTTPSドメイン、取得日時の原記録、原本SHA・物理ページ、元の期間・範囲・原区分、審査区分と制約を公開投影します。元の契約ファイルのローカルパスは出さず、照合用の不透明な契約参照IDだけを公開します。証拠の新規審査や不足値の推測は行いません。投影の SHA-256 は catalog とブラウザーの検証で照合し、件数・区分と許可の広がりを確認します。

この画面は検索・絞り込み・原値/出典の確認専用です。比較ワークスペースの系列、相関、グラフ、保存分析には追加しません。四半期782値・既存企業スナップショット・公的統計の読み込みや比較ゲートは従来のままです。ページで示す「元取得日時」は元 fact に記録がないとき未記録とし、資料審査日や後日の確認を取得日時へ転用しません。会社のFYラベルから実日付を生成しません。

長谷工の前年特命73.8%の既存 ID `38a9302411953bcfa71b0e3b8a4690c9e33f113437e18d582c670bf05890ccbe` は、原資料で実績と金額比を確認したものの、現行利用ゲートの actual が null のままです。この前年IDは1,400件の対象外です。対象内の当年91.7% ID `066a2a4b5f097a005c1aca209ac29f50c8c55993b5ef9328f8eb94b1e7e89107` は比較相手待ちのまま表示します。原資料の欠落を主張するものではなく、元 fact を保った期間別の読取投影と固定ペア契約の審査・実装が残ります。相手待ちの他の記録では、同じ原表に複数期間の数値が見える場合でも、列・期間・実績属性と各Factの対応を個別に証明する必要があります。表示上の候補を既存の比較相手として確定しません。
